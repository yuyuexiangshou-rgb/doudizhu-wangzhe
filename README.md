# 浮记 Float Counter

## 项目解决什么问题

浮记是一款面向「王者斗地主」画面的 Android 记牌悬浮工具。对局中，你可以通过悬浮条查看各牌点还剩几张，省去手动记录对手出牌的步骤。授权屏幕采集后，应用在本机识别横屏对局中可见的手牌、底牌和出牌，应用无需联网权限。

## 主要功能

- **实时记牌**。识别到 17 张或 20 张完整起手牌后建立记牌基线。叫地主阶段暂不记录出牌，进入出牌阶段后自动记录两位对手的可识别出牌，更新各牌点余量。自己的出牌不会被重复扣除。
- **双行悬浮条**。左侧显示牌点和对应余量，右侧显示识别状态、两位对手的剩余张数和最近出牌。悬浮条可以拖动、缩小、调整宽度和透明度，也可开启点击穿透。
- **记录和修正**。可查看本局已识别的对手出牌、撤销最近一次记录、手动扣除或加回一张指定牌点的牌，也可以暂停和恢复识别。
- **截图检查**。可导入游戏截图，查看识别出的手牌和两个对手区域的出牌。应用会在截图上标出识别位置，供检查使用。

## 安装方法

手机需要 **Android 8.0（API 26）或更新版本**。v0.5.0 发布提供源码，请按下方步骤构建 APK。[查看 v0.5.0 发布说明](https://github.com/yuyuexiangshou-rgb/doudizhu-wangzhe/releases/tag/v0.5.0)

请在 Windows 或 Linux 上使用 Git 获取源码，并准备 Python 3.9+ 和 JDK 17+。请确保 `python` 可用，且 JDK 已加入 `PATH` 或通过 `JAVA_HOME` 指定。

```sh
git clone https://github.com/yuyuexiangshou-rgb/doudizhu-wangzhe.git
cd doudizhu-wangzhe/assets/android-counter
python build.py
```

首次构建需要联网获取 Android SDK Platform 35 和 Build Tools 35.0.0。构建完成后，将 `build/FloatCounter-v0.5.apk` 传到手机，打开并按系统提示安装。覆盖安装需要相同签名，如需日后覆盖安装，请保留本地的 `.tools/debug.jks`。

只运行 Java 核心检查时，在 Android 工程目录执行 `python build.py --test-only`。Android 源码在 [assets/android-counter](assets/android-counter)，Codex skill 入口和排查说明见 [SKILL.md](SKILL.md)。使用 Codex skill 时，将包含 `SKILL.md` 和 `assets/` 的整个项目目录作为 skill 使用。

## 使用方法

1. 打开「浮记 · 斗地主」，点击「允许显示悬浮条」，在系统设置中授权。
2. 在游戏发牌前点击「开始实时记牌」，按系统提示授权屏幕采集。如果系统询问共享范围，请选择整个屏幕。随后切换到王者斗地主，保持横屏并避免遮住起手牌。
3. 完整起手牌识别成功后，悬浮条会显示各牌点的余量。拖动可以移动悬浮条，轻点可以打开操作菜单。开启点击穿透后，可在浮记首页或浮记通知中解锁。
4. 下一局发牌前，选择「重新开始记牌（下一局）」。当悬浮条显示本局已结束时，也可以直接轻点悬浮条重开。结束使用时，选择「停止并关闭悬浮条」。

单独检查截图时，在浮记首页点击「导入截图，立即识别」，选择一张完整的横屏对局截图。截图识别只用于检查，不参与实时记牌。

中途开启无法补记此前未采集到的出牌。漏帧时，部分牌点的余量可能偏多。当前源码版本为 v0.5.0，项目记录的两段对局录屏回放与人工标注的 9 手出牌一致，Android 实机表现仍需对照验证。

## 输入输出示例

**实时记牌**

- **输入**是一段实时游戏画面。你作为地主，20 张完整起手牌中没有 `3`。随后中间对手打出一张 `3`，其手牌从 17 张变为 16 张。
- **输出**中，确认起手牌后，悬浮条显示 `实时 · 余34`。这手牌记入后，`3` 下方的余量从 `4` 变为 `3`，状态变为 `实时 · 余33`，最近出牌显示 `中 16：3`。

**导入截图**

- **输入**为一张横屏对局截图，画面可见完整的 20 张手牌，两位对手的出牌区域为空。
- **输出**包含一张标出识别位置的截图，以及首页显示的识别结果。

```text
手牌 20张：大王 2 2 2 2 Q Q J J 10 10 10 10 6 5 5 5 5 4 4
中： / 右：
可建立完整起手牌基线
```
